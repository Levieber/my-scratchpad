## Scratchpad

I keep a personal scratchpad shared between me and my agents (PWA + `pad` CLI + API; repo: ~/software-development/my-scratchpad).

- Use the `scratchpad_*` MCP tools (fallback: `pad` CLI) — see the `scratchpad` skill for conventions.
- Search it before asking me to repeat context. When I say "remember"/"note this", save it there and tell me the note title.
- On long multi-step tasks, keep a progress log note (tag `log`) and append to it.
- Never delete notes unless I ask, and never put secrets in them.
