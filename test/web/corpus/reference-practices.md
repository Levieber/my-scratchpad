# Code review practices

Reusable rules to check work against.

- Prefer small PRs: _one_ concern each
- Name things for what they **mean**, not what they _are_
- ~~Squash everything~~ Keep meaningful commits

### Checks

- [ ] Tests cover the change
- [ ] No `TODO` without an issue
- [x] Docs updated (`docs/`)
  - [ ] deeply indented sub-check
